TypeSafe decision API, model jev-1.13.0. Key from the TypeSafe console. Never sent to the page.

Apple Silicon local runtime (~10ms/question). Install with pip install laya-mlx, then python scripts/laya_server.py. Same System One contract as Jev — no API key.

Keep if payload ≥ 2

Payload is contribution (0–3): a real point, a directed question, or a real joke. Open-ended “what’s your favorite / name one” reply-bait is not a point. At 2, blunt-but-real always stays visible.

Hide if noise ≥ 2

Noise is the highest of hijack (engineered packaging, including friendly reply-harvest), vacuity (no thought / tabloid-empty), persona (costume identity), and (if enabled) a bot-shaped follow graph. Hide only when payload is below the keep line and noise clears this floor. Named mutes stay on X.

Sends display name, handle, and bio to Jev as a persona / controversialness score. Also uses follower/following ratio, tweet volume, and join date as a local bot-shaped prior. Follow-graph discovery is untouched: this scores the author, not who you follow. Never overrides a real point.

X already stamps whether you follow the author on each timeline user — no following-list fetch. Those accounts get −1 on the noise used to hide (hijack 2 keeps; hijack 3 still hides). Jev still scores the post. Turn off to treat follows like everyone else.

Shown notes go to the classifier as context. Pending notes (if you're a contributor) appear on the score badge only — they do not hide a post.

Live log of classifications as you scroll. Turn off once you're tuned.
